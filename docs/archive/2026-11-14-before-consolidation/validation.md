## 本批三种主题的文本层演练（2026-11-13）

三种**互不相同的主题**（旧收据归档 / 阳台香草 / 旧照片相册）各演练一次，覆盖「有正文实操」「仅标题」「同主题定点编辑」三类请求，逐条走合并后的五步方法，记录实际决策。**全部为文本层推演：未调用图像生成工具、未产出新图、不冒充真实出图、不构成用户视觉验收**；生成后仍须按 SKILL.md「检查与交付」逐字核对与缩略图自检。

### 演练 A · 有正文实操（主题：旧收据 → 月度支出表）

- **输入**：虚构实操正文摘要「把一箱旧收据按月份分类、录入金额、汇总核对，得到一张月度支出表」，请求「给这篇内容做封面」。
- **内容入口**：有正文 → 先读正文，不走仅标题全文锁定；原文标题只用于识别文章。
- **实际文案（四层互补）**：标签「家庭记账」；说明「一箱收据变一张表」；主标题两行「旧收据 / 成月表」（精准短标题，不用「从收据到报表」这类泛泛长句）；底部流程「拍照 · 分类 · 汇总 · 核对」（正文实际步骤压缩，替代「完整实操」空泛重复）。四层各补一条新信息，不硬凑、不重复修饰。
- **隐喻**：一叠散乱收据纸 → 一个简单分类纸夹 → 一张带几行数字的支出表；只表达这一个核心转变，同一结果只出现一次，不把四个步骤各画成一个装置，不堆机器/多张表。**与通过样本的装置无关，换主题即换主体与动作。**
- **比例**：未指定 → 一张 4:3；提示词里的占比、字号、边距只作该画幅示例。
- **配色**：独立新任务、未指定颜色 → 任选「暖米橙纸」近纸白浅底 #F7F2EA / 深字 #4A3B2F / 低饱和强调 #DDB98C；配色不固定青色。
- **字体/背景**：全体现代无衬线（主标题利落黑体、辅文较轻），版画不带入宋体/明朝体；近纸白浅底、微弱暖色与细纸纹、深字对比、四角干净，标签与底部流程纸片可保留。
- **是否重生成**：首次任务 → **从新画布生成**，把上述文案、层级、隐喻、留白、字体、背景、配色、比例一次性写进同一条提示词；不设生成前文案审批关卡，不承诺一次成功。

### 演练 B · 仅标题（主题：阳台种香草，与 A 完全不同主题）

- **输入**：「用 $cover-design，给《给阳台种一盆会开花的香草》做一张封面」。
- **内容入口**：只有明确标题 → 直接生成，逐字保留。
- **实际文案**：`EXACT TEXT` 只写「给阳台种一盆会开花的香草」，不加标签、说明、流程、数字、功能、结论、身份或系列名，不硬凑四层；插画只画标题能支持的主题。
- **隐喻**：一颗种子纸包 → 一只小陶盆 → 一株开花的香草，同一结果只出现一次；不复用压机、不把抽象概念硬塞进无关机械道具。
- **比例**：未指定 → 一张 4:3。
- **配色**：另一个独立新任务且未指定颜色 → 可轮换到「苔绿纸」#F2F6EF / #26352C / #B9CE9E（仅为独立新任务间避免连续重复，不声称随机、不跨会话记忆）；仍为近纸白浅底。
- **是否重生成**：首次任务 → **从新画布生成**，一次性写全提示词；生成后逐字核对标题与缩略图可读性。

### 演练 C · 同主题定点编辑（主题：旧照片按年份归档成相册，与 A、B 均不同）

- **输入**：该主题此前已有一张用户认可的封面，用户说「只把主标题里的『按年份』改成『按地点』，另外背景再浅一点」。
- **内容入口**：同主题后续编辑，不重新提炼正文、不新增文案层、不换隐喻。
- **实际文案**：仅主标题两字替换与背景明度变化；该封面原有的标签、说明、底部流程及其余字形、字重、位置全部锁定。
- **隐喻**：不变（一叠散乱旧照片 → 一个分类纸夹 → 一本归档相册，同一结果只出现一次），不重画场景、不加减主体、不把正文步骤逐个画出来。
- **比例**：该封面原有比例（4:3）不变。
- **配色**：**同主题沿用**该封面已有的一套预设（此处假设「雾蓝纸」#F1F5F8 / #293F54 / #A8C3D6），只把纸面明度提浅并保留微弱色相与深字，不换预设、不重新选色、不生成色板。
