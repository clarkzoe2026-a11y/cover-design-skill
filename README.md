# 封面设计（cover-design）

把文章意思画出来，让标题先被读到。

一套用于文章、视频封面的 Codex / Agent skill：**一句话，或者只给一个标题，就能生成封面**，不需要填标签、副标题、色号、风格或比例。画面是浅色纸面、深色字、概念版画拼贴，也支持按需指定品牌主色、文字定点编辑与 **4:3、3:4、16:9** 重新构图。

![浅绿版画拼贴封面示例](skills/cover-design/assets/reference-4x3.png)

## 这套方法做什么

先明确读者要记住的词，再为内容选择可理解的动作隐喻。字体、字距、换行与留白先确定，插画为标题服务。它不是个人网站截图模板，也不是用同一套科技道具给不同标题换字。

有正文或摘要就提炼一句核心标题；只有标题就直接生成并逐字保留，不要求你补全文，也不会替你编造数字、功能、结论或身份。标签、副标题、配色、比例都是**可选自定义**：不说就由 skill 决定，不需要懂设计词或色号。

## 安装

克隆后将 skill 文件夹复制到 Codex 的技能目录；已有同名 skill 时先检查，不直接覆盖。

```bash
git clone https://github.com/clarkzoe2026-a11y/cover-design-skill.git
cd cover-design-skill
mkdir -p "$HOME/.agents/skills"
cp -R skills/cover-design "$HOME/.agents/skills/cover-design"
```

新开会话后调用 `$cover-design`。其他兼容 `SKILL.md` 的 Agent，可把该文件夹放入其技能目录。 skill 本身不调用付费 API；实际生成需要运行环境提供图像生成/编辑能力。没有工具时会报告限制，不把占位图当成品。

## 用法

一句话就行，不用填表：

```text
用 $cover-design，给《把散落笔记变成可复用知识库》做一张封面
```

已经有文章或摘要，也可以更省事：

```text
给这篇内容做封面
```

多个平台都要用图：

```text
同时做横版、竖版和宽屏三个版本
```

- 没指定比例时**默认只出一张 4:3**；「竖版」是 3:4，「宽屏 / 视频横封面」是 16:9，「三个版本」才生成三张并分别重排。不默认生成一堆图消耗额度。
- 没指定配色时从几套现成协调配色里选一套（浅底深字），不要求你先挑色号；同一个多比例批次用同一套配色。
- 想自定义时补一句就行：「标签：AI知识管理」「副标题：收集 · 整理 · 调用」「换成蓝色」「蓝一点」「换个颜色」「只把调用改成复用」。这些都是可选项，不填也能生成；「换个颜色」会锁住文案和构图，「只改字」会保留配色。

## 示例说明

示例为 AI 生成的同系列封面，包含建站教程的示例文字；没有个人网站截图、真实域名或备案号。它们用于理解画法与字图关系，不限制新主题的图像主体。16:9 示例原生尺寸存在像素取整差异，清单保留真实值。

不提供网页部署、API 代理或后台服务。下载项目不需要配置 Key；使用者的图像工具与额度由其所在环境管理。
