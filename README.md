# 封面设计（cover-design）

把文章意思画出来，让标题先被读到。

一套用于文章、视频封面的 Codex / Agent skill：**一句话，或者只给一个标题，就能生成封面**，不需要填标签、副标题、色号、风格或比例。画面是接近纸白的浅底、微弱低饱和色与深色字、全体现代无衬线文字、单一核心转变的概念版画拼贴，也支持按需指定品牌主色、文字或背景的定点编辑，以及从新画布重新生成与 **4:3、3:4、16:9** 重新构图。

## 这套方法做什么

先明确读者要记住的词，再为内容选择可理解的动作隐喻。同家族无衬线的主标题用 Bold、标签用 Medium、说明与流程用 Regular；字号与真实笔画粗细共同建立信息优先级。字体、字距、换行与留白先确定，插画为标题服务；字号、标签、说明、流程、插画、边距与留白作为一个整体协调安排，不靠巨黑字撑满。它不是个人网站截图模板，也不是用同一套科技道具给不同标题换字：换主题就换主体与动作，插画只表达一个核心转变，同一结果只出现一次。

有正文先读正文，提炼精准短标题，并把实际步骤压成简洁底部流程，各层各补一条新信息、不硬凑四层；只有标题就直接生成并逐字保留，不要求你补全文，也不会替你编造数字、功能、结论或身份。文案、层级、隐喻、字体、留白、背景、配色和比例会一次性写进同一条提示词再生成，没有生成前的文案审批关卡，也不承诺一次成功。标签、副标题、配色、比例都是**可选自定义**：不说就由 skill 决定，不需要懂设计词或色号。

16:9 短标题横版有[量化版式基线](skills/cover-design/references/ratios-and-edits.md#16-9-量化版式基线)：先定整组信息外框，再定文字、插画与纸片范围，避免忽大忽小。顶部标签可用同色系更鲜明的颜色提亮；内部保留自然撕边，画布四角干净。暖色背景以接近纸白的 #FCFAF6 为起点。坐标与色号是生成方向，仍需查看真实图片。

## 安装

克隆后将 skill 文件夹复制到 Codex 的技能目录；已有同名 skill 时先检查，不直接覆盖。

```bash
git clone https://github.com/clarkzoe2026-a11y/cover-design-skill.git
cd cover-design-skill
mkdir -p "$HOME/.agents/skills"
cp -R skills/cover-design "$HOME/.agents/skills/cover-design"
```

新开会话后调用 `$cover-design`。其他兼容 `SKILL.md` 的 Agent，可把该文件夹放入其技能目录。 skill 本身不调用付费 API；实际生成需要运行环境提供图像生成/编辑能力。没有工具时会报告限制，不把占位图当成品。

## 用法

一句话就行，不用填表：

```text
用 $cover-design，给《把散落笔记变成可复用知识库》做一张封面
```

已经有文章或摘要，也可以更省事：

```text
给这篇内容做封面
```

多个平台都要用图：

```text
同时做横版、竖版和宽屏三个版本
```

- 没指定比例时**默认只出一张 4:3**；「竖版」是 3:4，「宽屏 / 视频横封面」是 16:9，「三个版本」才生成三张并分别重排。不默认生成一堆图消耗额度。
- 没指定配色时从四套现成协调配色里选一套（都是近纸白浅底、各自微弱色相与深色字，不固定为青色），不要求你先挑色号；同一主题、多比例批次与后续编辑都沿用同一套配色。
- 想自定义时补一句就行：「标签：AI知识管理」「副标题：收集 · 整理 · 调用」「换成蓝色」「蓝一点」「换个颜色」「背景再浅一点」「只把调用改成复用」「重新生成一张」。这些都是可选项，不填也能生成；只改字、只换色或只提浅背景走定点编辑并锁住其余，明确要求重新生成或整体重设计时从新画布出图，不一刀切禁止编辑。
