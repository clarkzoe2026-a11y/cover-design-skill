# 封面设计 · 文字优先的版画拼贴封面

把文章的核心动作画成一个容易理解的场景，让标题在缩略图中先被读到。适用于独立封面，不用于制作网站页面、UI 原型或复刻个人作品集。

## 一句话就能用

面向非设计成员：**一句话就够了**，不要求填标签、副标题、色号、风格或比例等一串字段，也不设置生成前的脚本文案审批关卡。默认直接出图，生成后再按「检查与交付」自检。

- 有正文或现有摘要：提炼一句能概括内容的核心标题，其余文字不硬凑。
- 只有明确标题：直接生成，**逐字保留用户给的标题文字**；插画只表达这个标题本身能支持的主题，不要求用户补全文，不自行添加数字、功能、结论、身份、机构或系列名。
- 既没有标题也没有可用内容：才简短问一句「封面想讲什么主题？」，不追问其他字段。
- 标签、副标题是**可选自定义**：用户主动给了就用，没给就省略，不硬凑「四层文字」。用户指定原话时逐字保留；标点可按明确的排版需要换行，但不自行删字、改写或加卖点。
- 配色、风格、比例**不需要用户提供**：没给时按下面的「默认决策」自动补齐 —— 配色选一套现成预设、风格用默认的浅纸深字版画拼贴、比例默认一张 4:3。默认浅纸版画风格始终生效，不因为用户没写风格词就跳过设计。

## 默认决策：比例、配色与风格

**比例**：用户明确的比例或平台规格优先。没指定时默认**只生成一张 4:3**，不默认生成一堆图消耗额度。

| 用户的自然说法 | 处理 |
| --- | --- |
| 「竖版」 | 3:4 |
| 「宽屏」「视频横封面」 | 16:9 |
| 「三个版本」「全部常用比例」 | 4:3、3:4、16:9 各一张，分别重新构图 |
| 明确的平台像素/比例规格 | 按规格，并如实报告实际输出尺寸 |

**配色**：已有品牌色或上文指定色优先。没指定时，从 [配色与提示词](references/design-and-prompts.md) 的几套完整协调预设中选一套（浅底深字，有普通人能懂的名字；色号只是内部参考，不要求用户看懂或挑选）。**同一主题默认保留已有配色**：多比例批次、只改字、基于现有图继续调整，都沿用那一套，不重新选色。只有用户明确说「换个颜色」（或「蓝一点」等方向调整），或**可见上下文中出现另一个独立的新任务且未指定颜色**时，才重新选择；在几套之间轮换只是为了这类独立新任务之间避免连续重复，**不适用于**同一主题的后续批次与编辑。**不声称严格随机，也不依赖跨会话记忆**，不额外生成色板图。

自然话直接接受，不反问设计字段：「换个颜色」换一套预设并锁住文案、构图、字重、比例与其余部分；「蓝一点」「暖一点」按方向在预设内微调；「只把 X 改成 Y」保留现有颜色、字形、构图和比例。需要时读 [比例和编辑](references/ratios-and-edits.md)。

## 生成方法

1. 用一句可画的话定义隐喻：谁把什么从什么状态变成什么结果。选择一个连贯主体与动作，不把标题拆成一排抽象图标。只画标题能支持的主题，不要把同一幅房屋、手或浏览器图换字用于所有主题。
2. 应用选定的配色预设：浅色、低饱和背景 + 足够深的文字/刻线 + 少量强调色。主色是设计输入，不必整屏铺满；若用户要求深色底，遵从该要求并保持文字对比。需要时读 [配色与提示词](references/design-and-prompts.md)。
3. 字先于图：先安排合理换行、字重、基线和安全边距，再为插画分配空间。左文右图是横版的起点，竖版通常上文下图。明确「标题第一视觉重点、插画第二」；长标题用自然换行，不靠无上限增大字重或缩到看不清来塞满。
4. 版画细节、半色调、纸片叠层与柔和投影形成质感和纵深。保持文字周围安静。这个风格不依赖玻璃拟态、塑料立体道具、发光电路或软件截图。用户另有要求时按其方向设计，不把这些偏好变成所有封面的禁令。
5. 使用当前环境可用的图像生成/编辑工具生成图片。默认使用内置 ImageGen；没有工具时说明限制，交提示词或询问可用方案，不把代码画的占位图称为已生成成品，不自动切换付费 API。

参考图分别标注作用：字形与层级、画法、颜色或编辑目标。只借鉴用户要求的部分，不带入参考图的个人网站、真实人名、网址、客户案例或旧标题。自带 [横版风格参考](assets/reference-4x3.png) 只约束纸张、版画拼贴与字图关系，不是每张图都要复制的主体。

## 多比例与修改

- 4:3：可用左文右图，但标题长时缩小插画并保留明确间隔。
- 16:9：利用横向空间调整图文比例，不把 4:3 拉宽。
- 3:4：重新组织成上文下图或错位构图，不裁掉横版标题，不靠补边交差。
- 每个请求的比例单独生成，前一张已认可图可作风格参考。保留旧版，另存新版本。具体适配例见 [比例和编辑](references/ratios-and-edits.md)。
- 仅修改文字时，使用指定现有图为编辑目标，锁住其余字形、配色、内容和比例；不因两个字修改而重新设计整幅图。用户要求重设计时才重建构图。

## 检查与交付

查看生成后的真实图片，核对：文案逐字准确、重点词优先、无图文遮挡、边缘完整、隐喻对应主题、没有带入参考图的私人内容。缩略图检查文字能否先被读到；文件尺寸/哈希不能代替审美验收。

读取实际像素尺寸；原生输出可能有一像素量级的比例取整，报告真实尺寸，不把近似比例说成精确指定像素。严格像素要求未满足时继续处理或明确报告缺口。

把最终候选存入当前工作区，提供图片或下载链接；同时保留生成提示词、参考范围及实际尺寸。批量时用清单将每个主题映射到明确版本，不能按目录顺序猜。生成、自检、用户通过分别记录；用户没明确确认，不写「已验收」。
