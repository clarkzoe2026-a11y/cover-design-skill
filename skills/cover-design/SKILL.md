# 封面设计 · 文字优先的版画拼贴封面

把文章的核心动作画成一个容易理解的场景，让标题在缩略图中先被读到。适用于独立封面，不用于制作网站页面、UI 原型或复刻个人作品集。

## 一句话就能用

面向非设计成员：**一句话就够了**，不要求填标签、副标题、色号、风格或比例，不设生成前的脚本文案审批关卡，也不承诺一次成功。默认直接出图，生成后按「检查与交付」自检。先判断内容入口：

- **有文章链接**：先读取正文或找到可靠本地正文；读不到就说明缺口，不把未读正文当成仅标题任务。
- **有正文或摘要**：提炼**精准短标题**（说清核心动作、对象、结果；避免只写泛泛的起点和终点），再按内容选标签、说明、底部流程，让每层各补一条新信息；实操文章把正文步骤压成简洁流程，替代「完整实操」等空泛重复。原文标题只用于识别文章，不自动等于必须逐字上封面的文案；用户明确要求原话时才锁定。层数由内容决定，不硬凑四层，删掉不增加信息的重复修饰。
- **只有明确标题**：直接生成，**逐字保留标题文字**；插画只表达标题本身能支持的主题，不要求补全文，不添加数字、功能、结论、身份、机构或系列名。
- **标题与可用内容都没有**：才简短问一句「封面想讲什么主题？」，不追问其他字段。

标签、副标题可由用户指定，也可在有正文时据内容提炼；仅有标题且无补充内容时省略，不凭空编造。配色、风格、比例**不需要用户提供**，按「默认决策」自动补齐。

## 默认决策：比例、配色与风格

**比例**：用户明确的比例或平台规格优先；没指定时默认**只生成一张 4:3**，不默认生成一堆图消耗额度。

| 用户的自然说法 | 处理 |
| --- | --- |
| 「竖版」 | 3:4 |
| 「宽屏」「视频横封面」 | 16:9 |
| 「三个版本」「全部常用比例」 | 4:3、3:4、16:9 各一张，分别重新构图 |
| 明确的平台像素/比例规格 | 按规格，并如实报告实际输出尺寸 |

**配色**：已有品牌色或上文指定色优先；否则从 [配色与提示词](references/design-and-prompts.md) 的四套预设中选一套。四套都是**接近纸白的浅底**，各自带一点微弱色相与足够深的字，强调色只用于标签或一小块纸片；**不固定为青色**。**同一主题默认保留已有配色**：多比例批次、只改字、只改色、基于现有图继续调整都沿用那一套。只有用户明确说「换个颜色」（或「蓝一点」等方向微调），或可见上下文中出现另一个独立的新任务且未指定颜色时才重新选；轮换只用于这类独立新任务，不声称严格随机、不依赖跨会话记忆、不额外生成色板图。

**风格基线**：背景接近纸白，只留微弱低饱和色与细纸纹，深色字保持对比；四角默认干净，不额外加角落撕纸；内部标签、底部流程纸条与连接纸带保留自然撕边、细纤维和柔和纸影，不因清理四角而一起抹平。顶部标签可在同色系内使用比背景更鲜明的强调色，以小面积提亮，保持深字对比，避免荧光感；其余区域仍低饱和。全体文字用同一家族的现代无衬线，以信息优先级同时分配字重与字号：主标题 Bold、标签 Medium、说明与底部 Regular，插画里的示例文字也应从属；不能各层都用粗黑字，也不能只靠缩字号或降低透明度伪装轻重。字重数值与字形高度参考见量化版式基线；版画刻线、半色调、纸片叠层与柔和投影只用于插画与纸张，**不带入宋体、明朝体等衬线字**。用户另有要求时按其方向设计并保持文字对比，不把这些偏好变成所有封面的禁令。

自然话直接接受，不反问设计字段：「换个颜色」换一套预设并锁住文案、构图、字重、比例与其余部分；「蓝一点」「暖一点」按方向在预设内微调；「只把 X 改成 Y」保留现有颜色、字形、构图和比例。需要时读 [比例和编辑](references/ratios-and-edits.md)。

## 生成方法：一次写全生成规格

1. **定文案**：按上面的内容入口产出一套互补文案。主标题用最少且准确的字说明核心动作、对象与结果；标签、说明、流程各补一条新信息，说明和步骤用较小文字，避免两行长文同等加粗。用户明确指定封面原话时逐字保留。
2. **定隐喻**：用一句可画的话定义「谁把什么从什么状态变成什么结果」。插画只表达这一个核心转变，**同一结果只出现一次**；不把正文每一步都画出来，不堆机器、胶卷或多个视频帧。换主题就换主体与动作，不把某一篇文章的装置、房屋、手或浏览器换字复用到所有主题；只画标题能支持的内容。
3. **定版式**：把标签、说明、主标题、流程、插画、边距与留白**作为一个整体协调安排**，需要时联动缩放与重排。先约束整组信息的外框，再协调标题与插画，避免边缘塞满或缩成中央小团；16:9 横版采用[量化版式基线](references/ratios-and-edits.md#16-9-量化版式基线)，不能只写「中等字号／多留白」；文字区域占半幅**不等于字形撑满**，不机械放大文字，也不强制隔成两栏。横版左文右图、竖版上文下图只是起点；纸片延伸与适度叠合可让字图成为一个整体，文字压在安静图面上时保持清晰，不让插画盖住笔画。引号、纸片也计入安全边界；按当前画幅把整组外框、各层范围、字形高度与行间净距一起写入提示词。16:9 基线是可复用起点，生成后复核偏差；换比例、长标题或用户另有布局要求时重设，不将像素值硬套到所有画幅。
4. **一次写全提示词再生成**：把文案与层级、主隐喻、版式与留白、字体、背景、配色、比例**一次性完整写进同一条提示词**，再交给当前环境可用的图像生成/编辑工具出图。默认使用内置 ImageGen；没有工具时说明限制，交提示词或询问可用方案，不把代码画的占位图称为成品，不自动切换付费 API。不承诺一次成功；生成后按「检查与交付」逐字核对文案并看缩略图。
5. **重生成还是定点编辑**：整体重设计，或用户明确要求「重新生成 / 别在旧图上改」时，**从新画布生成**，不把提示词拆成多次补丁叠在旧图上。只改字或只改颜色时仍走**定点编辑**，以指定现有图为编辑目标，锁住其余字形、配色、构图与比例；不一刀切禁止编辑。两个分支按用户意图区分，见「多比例与修改」。

当前效果参考：[雾蓝字重层级](assets/reference-mist-blue-16x9.png)、[暖纸白与橙色标签](assets/reference-warm-paper-white-16x9.png)。借鉴层级、体量与纸张关系，不复制示例文案或主题；两图的确认范围见仓库效果图清单。

参考图分别标注作用：字形与层级、画法、颜色或编辑目标。只借鉴用户要求的部分，不带入参考图的个人网站、真实人名、网址、客户案例或旧标题。自带 [横版风格参考](assets/reference-4x3.png) 只约束纸张、版画拼贴与字图关系，不是每张图都要复制的主体；只借画法时按当前标题长度重设字号。

## 多比例与修改

- 4:3：左文右图可作起点，标题长时缩小插画并保留明确间隔。
- 16:9：利用横向空间调整图文比例，不把 4:3 拉宽。
- 3:4：重新组织成上文下图或错位构图，不裁掉横版标题，不靠补边交差。
- 每个请求的比例单独生成，前一张已认可图可作风格参考；保留旧版，另存新版本。具体适配例见 [比例和编辑](references/ratios-and-edits.md)。
- 定点编辑（只改字 / 只改色）：以指定现有图为编辑目标，锁住其余文案、字形、配色、构图、比例；不因两个字或一次背景提浅就重建整幅图。
- 从新画布生成（整体重设计 / 明确重新生成）：不传旧图作编辑目标，按上面 5 步重新构图。

## 检查与交付

查看生成后的真实图片，逐字核对文案、层级与重点词，检查无图文遮挡、边缘与四角完整干净、隐喻对应主题、没有带入参考图的私人内容；用缩略图检查标题能否先被读到。文件尺寸/哈希不能代替审美验收。

16:9 先按量化基线检查整组信息范围，再看字形、插画与撕纸关系；指标只作过空／过满的复核提示，不因数值达标就宣布视觉通过。

读取实际像素尺寸；原生输出可能有一像素量级的比例取整，报告真实尺寸，不把近似比例说成精确指定像素。严格像素要求未满足时继续处理或明确报告缺口。

把最终候选存入当前工作区，提供图片或下载链接；同时保留生成提示词、参考范围及实际尺寸。批量时用清单将每个主题映射到明确版本，不能按目录顺序猜。生成、自检、用户通过分别记录；用户没明确确认，不写「已验收」，也不把某一版的通过套给其它版本。
